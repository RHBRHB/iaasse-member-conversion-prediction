# Member Conversion Prediction Model

## Project Overview

Machine learning project designed to predict whether a free-tier
user is likely to convert to a paid membership.

## Objective

Predict paid conversion using user registration and early
platform engagement behavior.

## Dataset

A public e-learning dataset from 365 Data Science is being used
as a proxy dataset because IAASSE historical membership data was
not available.

## Prediction Target

converted_to_paid

0 = Did not convert
1 = Converted to paid

## Prediction Setup

User behavior during the first 7 days after registration is used
to predict conversion during the following 90-day period.
